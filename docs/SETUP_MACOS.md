# Установка PSP Deck на macOS

Сервер кроссплатформенный: тот же код работает на Windows, macOS
и Linux. Клиент на PSP один и тот же — пересобирать не нужно.

## Запуск

```sh
cd server
python3 -m pip install --user -r requirements.txt
python3 pspdeck_server.py
```

## Права macOS (важно!)

Для синтеза клавиш (действия `hotkey` / `text`) macOS требует
выдать разрешения:

1. **Системные настройки -> Конфиденциальность и безопасность ->
   Универсальный доступ** — добавить приложение Терминал
   (или iTerm/Terminal, из которого запускается сервер).
2. При первом нажатии hotkey-кнопки macOS может дополнительно
   спросить **Мониторинг ввода** — разрешить.

Без этих прав `run` и `url` работают, а `hotkey`/`text` — нет
(сервер честно напишет об этом в лог).

Если включён брандмауэр macOS (Системные настройки -> Сеть ->
Брандмауэр), разрешите входящие подключения для python3.

## Пример конфигурации под macOS

См. `server/config.mac.json.example`. Отличия от Windows-версии
только в командах запуска — используется `open`:

```json
{ "label": "TextEdit", "color": "#4a7bd0",
  "action": { "type": "run", "cmd": "open -a TextEdit" } }
```

Горячие клавиши пишутся так же; клавиша Command называется
`cmd` (или `win`). Примеры: `cmd+shift+3` (скриншот),
`cmd+c`, `ctrl+cmd+q` (блокировка экрана).

## Точка доступа на Mac (прямое подключение без роутера)

macOS умеет раздавать Wi-Fi только если интернет приходит по
**кабелю** (Ethernet):

**Системные настройки -> Основные -> Общий доступ -> Общий доступ
к интернету**: «Поделиться подключением» = Ethernet, «Пользователям
компьютеров» = Wi-Fi → Параметры Wi-Fi (имя/пароль, канал).

Если Mac подключён к интернету по Wi-Fi, раздать ту же сеть
он не сможет — используйте роутер или Windows-ПК с мобильной
точкой доступа.
