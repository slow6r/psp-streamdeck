# Установка PSP Deck

## Часть 1. ПК на Windows 11

### Python

1. Скачать Python 3.11+ с https://www.python.org/downloads/
2. При установке обязательно отметить галочку **Add python.exe to PATH**.

### Зависимости и запуск

Открыть командную строку в папке `server` и выполнить:

```
pip install -r requirements.txt
python pspdeck_server.py
```

При первом запуске Windows спросит про брандмауэр — нажать
**Разрешить доступ**. Рекомендуется отметить **и Частные, и
Публичные сети**: сеть от точки доступа ПК (см. ниже) Windows
может классифицировать как публичную.

Если окно брандмауэра не появилось / PSP не находит ПК:

```
Параметры -> Сеть и Интернет -> Брандмауэр Защитника Windows ->
Разрешить взаимодействие с приложением -> найти Python ->
галочки «Частные» и «Публичные»
```

Окно сервера можно сворачивать — оно должно оставаться запущенным.

### Прямое подключение без роутера (точка доступа на ПК)

Если PSP плохо цепляется к домашней сети, ПК может раздавать
собственную Wi-Fi сеть — PSP подключается напрямую к компьютеру,
роутер не нужен. Код менять не требуется: сервер слушает все
интерфейсы, автопоиск найдёт его в этой сети.

1. **Параметры -> Сеть и Интернет -> Мобильная точка доступа -> Вкл.**
2. Нажать **Изменить** (свойства сети) и выставить:
   - Имя сети: например `PSPDECK`
   - Пароль: не короче 8 символов
   - **Диапазон: 2,4 ГГц** — обязательно! PSP не видит сети 5 ГГц.
   - **Тип безопасности: WPA2** — PSP не поддерживает WPA3.
3. На PSP в диалоге выбора сети создать новое подключение к `PSPDECK`
   (сканирование найдёт её, ввести пароль, настройки — Easy).
4. Для стабильности: на PSP в **Настройки сети -> Power Save Off**
   (экономия энергии Wi-Fi снижает качество связи).

Интернет на PSP при этом не обязателен — нужен только обмен
с сервером. Если ПК подключён к интернету по Ethernet, точка
доступа работает одновременно с ним без конфликтов.
Остановка — `Ctrl+C` в окне сервера.

## Часть 2. PSP

1. Подключить карту памяти PSP к компьютеру.
2. Скопировать `psp/EBOOT.PBP` в папку `PSP/GAME/PSPDECK/`
   на карте (папки создать, если нет).
3. Включить Wi-Fi тумблером (сверху слева корпуса).
4. На PSP: **Игры -> Memory Stick -> PSP Deck**.
5. При первом запуске откроется системный диалог сети — выбрать
   свою Wi-Fi сеть (или существующее подключение) и дождаться
   получения IP. PSP запомнит выбор.

Важно: PSP и ПК должны быть в **одной Wi-Fi сети**, а на роутере
должна быть выключена изоляция клиентов (AP/client isolation).

### Если «SCAN...» долго не превращается в «LINK OK»

- Сервер запущен? В его окне должно появиться «PSP найден: ...».
- Если строки про PSP нет — виноват брандмауэр или разные сети.
- Если строка есть, а LINK OK нет — посмотреть лог сервера на ошибки.

## Часть 3. Настройка кнопок

Кнопки описаны в `server/config.json`. Формат — в README.md.
Конфиг перечитывается при каждом новом подключении PSP: чтобы
применить изменения, достаточно переподключиться (выйти и зайти
в игру на PSP, либо перезапустить сервер).

## Проверка без PSP (опционально)

Имитатор клиента на любой машине с Python в той же сети:

```
python3 tools/test_client.py <ip-компьютера-с-сервером>
```
