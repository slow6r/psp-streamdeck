# PSP Stream Deck

PSP как физическая панель макро-клавиш (Stream Deck) для ПК.

Экран приставки показывает сетку кнопок — запуск программ, хоткеи,
открытие сайтов. Крестовина выбирает кнопку, **X** нажимает, **L/R**
переключают страницы. Связь с ПК по Wi-Fi домашней сети.

```
[PSP-3000+ · C] <--Wi-Fi--> [ПК, Windows · Python-сервер]
 экран 480x272                    config.json + выполнение действий
```

## Состав

| Папка    | Что это                                        |
|----------|------------------------------------------------|
| `psp/`   | Клиент для PSP (C, PSPSDK). Сборка → `EBOOT.PBP` |
| `server/`| Сервер для ПК (Python 3) + `config.json`       |
| `docs/`  | Инструкция по установке                        |
| `tools/` | Генератор шрифта и тестовый клиент             |

## Возможности

- Автопоиск ПК в сети (UDP broadcast) — IP вводить не нужно.
- До 8 страниц × 8 кнопок; подписи на русском и английском.
- Типы действий: `run` (запуск программы/скрипта), `hotkey`
  (комбинации клавиш, мультимедиа-клавиши), `url` (открыть сайт),
  `text` (ввести текст).
- Автопереподключение, индикатор связи и заряда батареи.
- Выбор Wi-Fi — стандартным системным диалогом PSP.

## Быстрый старт

Подробно — в [docs/SETUP.md](docs/SETUP.md). Кратко:

1. **PSP:** скопировать `psp/EBOOT.PBP` на карту в `PSP/GAME/PSPDECK/`.
2. **ПК (Windows):** поставить Python 3.11+ с python.org,
   `pip install pynput`, запустить `python pspdeck_server.py`,
   разрешить доступ в брандмауэре (частные сети).
3. Включить Wi-Fi тумблером на PSP, запустить **PSP Deck** из
   «Игры → Memory Stick», выбрать сеть в диалоге.
4. Готово — кнопки нажимаются крестиком.

## Сборка клиента (на Mac)

Требуется запущенный Docker Desktop:

```sh
cd psp
./build.sh          # → EBOOT.PBP
./build.sh clean    # очистка
```

Шрифт пересобирается так (нужен Pillow, нужен macOS):

```sh
python3 tools/genfont.py   # → psp/font8x8.c + tools/preview.png
```

## Протокол

Текстовый, построчный. Discovery — UDP broadcast на порт 50000:

```
PSP -> *:50000   PSPDECK_DISCOVER
ПК  -> PSP       PSPDECK_SERVER <ip> <tcp-port>
```

Дальше TCP (порт 50001), строки в UTF-8 через `\n`:

```
PSP -> ПК   HELLO PSPDECK 1
ПК  -> PSP  LAYOUT <страниц>
            PAGE <имя>
            BTN <rrggbb> <подпись или ->   ×8 на страницу
PSP -> ПК   PRESS <страница> <кнопка>      -> ПК отвечает OK
PSP -> ПК   PING                           -> ПК отвечает PONG
```

Клиент шлёт PING каждые 5 с; если PONG не приходит 12 с —
переподключение.

## Настройка кнопок

Редактируется `server/config.json` (перечитывается при каждом
подключении PSP — перезапускать сервер не нужно):

```json
{ "pages": [ { "name": "Главные", "buttons": [
    { "label": "Блокнот", "color": "#4a7bd0",
      "action": { "type": "run", "cmd": "notepad.exe" } },
    { "label": "Скриншот", "color": "#c05050",
      "action": { "type": "hotkey", "keys": "win+shift+s" } }
] } ] }
```

Действия:

| type    | поля                 | пример                          |
|---------|----------------------|---------------------------------|
| `run`   | `cmd`                | `"cmd": "notepad.exe"`          |
| `hotkey`| `keys` (через `+`)   | `"keys": "ctrl+shift+s"`, `"play"`, `"volumeup"` |
| `url`   | `url`                | `"url": "https://youtube.com"`  |
| `text`  | `text`               | `"text": "hello"`               |

Имена клавиш: буквы/цифры, `ctrl alt shift win`, `enter tab space esc
backspace delete up down left right`, `f1..f12`, мультимедиа: `play
next prev volumeup volumedown mute`, `printscreen`.

## Управление на PSP

| Кнопка     | Действие                |
|------------|-------------------------|
| Крестовина | выбор кнопки            |
| X          | нажать                  |
| L / R      | предыдущая / следующая страница |
| START      | выход                   |
| HOME       | выход (стандартный)     |

## Ограничения

- Hotkey/text требуют `pynput` и работают в пределах прав сервера
  (в некоторых приложениях «от администратора» клавиши доводятся
  не до всех окон — это ограничение Windows, не протокола).
- Разброс задержки нажатия по Wi-Fi — единицы-десятки миллисекунд.
